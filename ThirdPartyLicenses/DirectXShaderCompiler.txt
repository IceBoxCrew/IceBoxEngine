DirectX Shader Compiler (dxcompiler.dll) and DXIL signing library (dxil.dll)

Redistributed on Windows only, next to the engine binaries and next to a
Windows game built with IceBox Engine, whenever the Direct3D 12 backend is
available. They compile HLSL to DXIL at shader model 6.x, which is what the
Direct3D 12 backend and hardware ray tracing need; without them that backend
falls back to the legacy FXC compiler at shader model 5.1.

Both files are taken unmodified from the Redist\D3D\<arch> folder of the
installed Windows SDK, which is where Microsoft places them for redistribution.
They are Microsoft "Distributable Code" and are redistributed exactly as the
Visual Studio and Windows SDK licence terms permit.
See https://visualstudio.microsoft.com/license-terms/

No other target platform redistributes them: Direct3D 12 exists only on Windows
and Xbox. Linux, macOS, iOS, Android and Web use Vulkan, Metal, OpenGL/GLES or
WebGL and compile their shaders with shaderc and SPIRV-Cross, which are covered
by shaderc.txt, glslang.txt, SPIRV-Tools.txt, SPIRV-Headers.txt and
SPIRV-Cross.txt.
